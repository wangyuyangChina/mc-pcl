使用 Microsoft 设备代码登录，不会要求你把密码交给启动器

需在 Microsoft Entra 注册“公共客户端/移动和桌面应用”，允许设备代码流。Client ID 是公开标识，不要填写 Client Secret。也可在启动器进程环境变量中设置 MC_PCL_CLIENT_ID。
